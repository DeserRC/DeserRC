## What I build

**Software architecture** &nbsp;·&nbsp; distributed systems, DDD, microservices, service decomposition, system modernization

**Backend systems** &nbsp;·&nbsp; scalable services, APIs, distributed processing, messaging, concurrency

**Security engineering** &nbsp;·&nbsp; secure-by-default architectures, IAM, access control, data protection, LGPD and ISO 27001

**Monitoring & observability** &nbsp;·&nbsp; metrics, centralized logging, real-time dashboards, alerting, SIEM, incident visibility

**High-performance systems** &nbsp;·&nbsp; high throughput, low latency, real-time processing, event-driven architectures

**Game backends** &nbsp;·&nbsp; real-time infrastructure, multiplayer systems, networking, event-driven architectures

**Financial platforms** &nbsp;·&nbsp; credit and risk engines, bureau integrations, auditable decision flows

**Cloud & platform engineering** &nbsp;·&nbsp; container orchestration, CI/CD, multi-cloud infrastructure, production reliability
